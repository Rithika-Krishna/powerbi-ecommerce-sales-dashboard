# 📊 E-commerce Sales Dashboard - Power BI Project

This project is a comprehensive analysis of e-commerce sales data using **Power BI**. It provides insights into customer behavior, product performance, order trends, and sales performance across various categories.

## 🚀 Overview

This dashboard was built using:
- **Power BI Desktop** for data visualization
- **Orders.csv** & **Details.csv** as data sources

The `.pbix` file includes:
- Data cleaning and transformation in Power Query
- Relationships defined between datasets
- Multiple insightful dashboards and visuals

## 📈 Key Insights

- Monthly and quarterly sales trends
- Top-selling products and categories
- Customer segmentation and behavior analysis
- Profit margins and high-value orders
- Order status tracking (delivered, pending, etc.)

## 📂 Files Included

- `ecommerce sales.pbix` – Main Power BI dashboard
- `Orders.csv` – Order level transactional data
- `Details.csv` – Product and category details

## 🧠 Skills Demonstrated

- Data cleaning and transformation using Power Query
- Data modeling with relationships
- Advanced DAX formulas for custom KPIs
- Visual storytelling and dashboard design
- Business insight derivation from raw data
